# PlasmaDeck Branding

PlasmaDeck (PD) uses a minimal KDE Plasma inspired identity: rounded cards, Breeze-compatible blue accents and high-contrast typography.

## Assets

- `assets/icons/plasmadeck.svg`: scalable application icon.
- `assets/logos/plasmadeck.svg`: default logo.
- `assets/logos/plasmadeck-light.svg`: logo optimized for light backgrounds.
- `assets/logos/plasmadeck-dark.svg`: logo optimized for dark backgrounds.

## Visual principles

- Native Qt, no web shell.
- Breeze-like colors: `#3daee9`, `#eff0f1`, `#31363b`.
- Rounded cards and restrained gradients.
- Legibility over dense telemetry.
